# Bad Expenses
App tracking perbelanjaan bulanan: bajet, rekod belanja, graf dan report lebihan.

## Deploy ke GitHub Pages
1. Buat repo baru `bad-expenses`.
2. Upload semua fail dalam folder ini.
3. Settings > Pages > Deploy from a branch > `main` / root.
4. Buka `https://<username>.github.io/bad-expenses/`, kemudian tekan Import data.

**Jangan upload fail data (.json) ke repo.** Data disimpan dalam browser (dan Supabase jika disambung).

Supabase: run `supabase.sql`, kemudian `token.sql`.
